# Contributing to Relay Room

Thanks for helping improve Relay Room. Issues, documentation updates, bug fixes, and focused feature pull requests are welcome.

## Development

1. Install Node.js 22.13 or newer.
2. Install dependencies with `npm ci`.
3. Start the app with `npm run dev`.
4. Run `npm run lint` and `npm test` before opening a pull request.

Keep changes focused, explain user-visible behavior in the pull request description, and include or update tests when behavior changes. Do not commit secrets, local environment files, generated build output, or deployment credentials.

## Pull requests

Please describe the problem, the approach, and how you validated the change. Changes to the game flow, WebMCP tools, assets, or deployment behavior should call out compatibility and manual testing considerations.
